01 / Overview

At a glance

A bilingual evaluation project comparing how LLMs respond to MCQs in Dzongkha and English.

What this demonstrates: Shows how evaluation design can reveal language coverage gaps and benchmark limitations.

Case-study scope: factual project purpose is based on Novin's description. The workflow shown below is a proposed or general technical direction, not proof that every step is implemented.

02 / Context

The problem and the objective

The challenge

Language-model performance can vary by language. A meaningful comparison needs equivalent questions, controlled prompts and clear scoring criteria.

The goal

Compare responses on Dzongkha and English MCQs using a consistent evaluation structure.

03 / Reasoning

How the project can be approached

The following three-part structure describes a defensible development and evaluation path for this project.

01

Build comparable MCQs

Organize language-matched questions with answer keys and topic labels.

02

Run models consistently

Use aligned instructions and record predictions for each language.

03

Score and interpret

Check accuracy, invalid answers and differences without overinterpreting small samples.

05 / Judgment

Important design and research decisions

Question parity

Translation quality and subject difficulty can distort the comparison if they are not controlled.

Transparent scoring

Model names, versions, prompts and evaluation dates should accompany any reported numbers.
