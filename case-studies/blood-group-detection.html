01 / Overview

At a glance

An exploratory project investigating whether fingerprint features can support blood-group prediction.

What this demonstrates: Combines a real-world classification question with dataset quality, responsible AI and evaluation discipline.

Case-study scope: factual project purpose is based on Novin's description. The workflow shown below is a proposed or general technical direction, not proof that every step is implemented.

02 / Context

The problem and the objective

The challenge

Blood-group determination ordinarily requires blood-based laboratory testing. This project explores a different research question: whether fingerprint images show predictive patterns in a given dataset.

The goal

Study the potential and limitations of fingerprint-based classification rather than treat the output as a confirmed blood type.

03 / Reasoning

How the project can be approached

The following three-part structure describes a defensible development and evaluation path for this project.

01

Fingerprint input

Study fingerprint image examples and the labels attached to them.

02

Prepare and learn

Clean and prepare images; train and compare candidate classifiers when data permits.

03

Evaluate carefully

Test on independent people and examine class imbalance, leakage and uncertainty.

05 / Judgment

Important design and research decisions

Research, not diagnosis

A fingerprint-based prediction must never be presented as a medically verified blood-group result.

Evidence matters

Model performance, sample size, validation design and any data leakage need to be reported before claims of accuracy.
